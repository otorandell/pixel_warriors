# Session 2026-03-22 — Inline Sprite Icons

## What was done
Added a TMP Sprite Asset-based icon system to replace text-based status indicators (`[S][B][Po]`) with colored pixel art sprites inline with text.

### New files
- `Assets/Editor/PixelIconGenerator.cs` — Editor script with two menu items:
  - **Tools > Generate Status Icons Sprite Sheet**: Creates a 128x64 PNG with 32 white-on-transparent 16x16 pixel icons defined as bitmasks
  - **Tools > Create Status Icons TMP Sprite Asset**: Creates a TMP_SpriteAsset using reflection to bypass Unity 6's read-only properties
  - **Tools > Debug TMP_SpriteAsset Fields**: Helper to list all field names (used during development)
- `Assets/Scripts/UI/IconConfig.cs` — Static class mapping StatusEffect → sprite name + tint color, with helpers for inline sprite tags and resource icon shortcuts

### Modified files
- `Assets/Scripts/UI/CharacterCardUI.cs`:
  - Status indicators now use sprite icons via `IconConfig.GetStatusSprite()` with automatic fallback to text codes
  - HP/EN/MP lines use icon prefixes (heart, lightning, mana drop)
  - Expanded displayed effects to include Envenom, Imbue, UltimateReflexes, Caltrops, Levitate, Confusion, CorpseExplosion, LeechLife, Bodyguard, ElementalArmor
  - Rich text + sprite asset enabled on classLevel, HP, energy, and mana text components
- `CLAUDE.md` — Updated current state, roadmap, decisions

## Key decisions
- **TMP Sprite Assets over icon fonts** — SDF rendering blurs pixel art; bitmap sprites stay crisp
- **White icons + runtime tinting** — One sprite set, color controlled per-status via `<color=#hex><sprite tint=1></color>`
- **Programmatic icon generation** — Fits code-first workflow; icons replaceable by swapping the PNG

## Unity 6 TMP gotchas discovered
- `TMP_SpriteAsset.spriteGlyphTable` is read-only (no setter)
- Actual glyph table field is `m_GlyphTable` (NOT `m_SpriteGlyphTable`)
- Character table field is `m_SpriteCharacterTable`
- Must set `m_Version` to `"1.1.0"` via reflection to prevent `UpgradeSpriteAsset()` NullReferenceException
- `TMP_SpriteAsset` is the correct type (not `UnityEngine.TextCore.Text.SpriteAsset`) — `TextMeshProUGUI.spriteAsset` expects it
- Editor files must use namespace `PixelWarriors` (not `PixelWarriors.Editor`) and no `#if UNITY_EDITOR` wrapper
