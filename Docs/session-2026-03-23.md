# Session 2026-03-23 — Phase 6: Systems Overhaul

## Summary
Major systems overhaul to finalize game mechanics before the class ability content pass. All core systems locked down.

## Changes Made

### 1. Passive System Refactor
- Added `PassiveEffect` enum (26 values) replacing all string-based `HasPassive()` calls
- `AbilityData.PassiveEffect` field, `BattleCharacter.HasPassiveEffect()` method
- 19 call sites updated across PassiveProcessor, ActionExecutor, PriestAbilityHandler
- Zero string matching remains

### 2. Pick-to-Level System
- Removed XP system entirely (CurrentXP, AddXP, CalculateXPToLevel, all XP configs)
- After each combat: player picks 1 of 2 offered characters to level up
- Pseudo-random candidate selection, avoids repeat offers, excludes max level characters
- Boss fights grant 2 level-ups
- Events/rest can grant level-ups via `PendingEventLevelUp` flag
- Max level 21 (last passive at 20, last ability at 21)
- New `LevelUpPickScreen` with stat preview and next unlock display

### 3. Run Structure
- 4 acts × 20 floors = 80 floors (was 3 × 7 = 21)
- Boss on floor 20 of each act
- 4th biome: The Abyss (enemies TBD)
- Party starts with 4 characters (was 2 + recruit)
- Removed Recruit room type and RecruitPhase

### 4. Room Flow Rework
- Three floor categories: Battle (mandatory), Bonus (choose bonus or fight), Event
- `FloorGenerator.GenerateActPlan()` creates entire act floor plan upfront
- Battle rooms: ~10-12 per act, elites increase with progression
- Bonus rooms: ~4-5 per act (Shop, Rest, Smithy)
- Events: ~3-4 per act
- Floor plan persisted in save data
- Smithy room type added (stubbed to shop for now)

### 5. Tab Restructure
- 4 tabs: Generic > Attacks > Skills > Spells (was 5 tabs)
- Attack ability moved to Generic tab
- Consumable items merged into Generic tab
- Items tab removed
- Default tab is Generic on character select

### 6. Combatant Manual System
- Starting generics trimmed to: Attack, Swap, Hide, Pass
- Reposition, Anticipate, React, Taunt now learned via Combatant Manuals
- 4 Manual consumables (40-50g each, available from act 1)
- Manuals appear in shops alongside Books (20% chance combined)
- Uses same teach UI as Books in InventoryScreen

### 7. Annihilation Debug Ability
- Re-enabled for testing (0 cost, kills all enemies)

## Design Decisions Documented
- Full design doc at `Docs/design-phase6-overhaul.md`
- Smithy design: materials (Metal/Leather scraps + Gems), upgrade/craft/dismantle/imbue
- Biome plan: Sewers > Wilderness > Dark Citadel > The Abyss (2 options per act TBD)
- Leveling math: ~60-74 level-ups per run, focused play gets 1-2 chars to 21
- Future colored skill points concept (deferred)
